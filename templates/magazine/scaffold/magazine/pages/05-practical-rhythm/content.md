Start with the reader outcome. Give each page one dominant idea, one clear
hierarchy, and enough breathing room to understand where attention should move.

Then iterate locally:

1. revise one page's metadata or prose;
2. rebuild both themes;
3. inspect the synchronized outputs;
4. commit the smallest coherent change;
5. request human review before publication.

Raster-first pages remain valid when the artwork is the authored page. Semantic
text and alternative descriptions still accompany them so the web edition is
not reduced to an inaccessible image gallery.
