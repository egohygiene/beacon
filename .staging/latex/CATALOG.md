# LaTeX reference catalog

Browse the retained reference families below. These are outside the active
[template registry](../../templates/README.md). Existing source licenses apply;
a catalog entry does not certify build readiness, accessibility, or current
publisher compliance. See the [component-library direction](../../docs/latex-component-library.md).

## Reviewed additions — October 25, 2026

- [IEEE conference starter](Academic%20Journals/ieee-conference/README.md): original neutral starter; upstream dependency installed separately.
- [IEEEtran BibTeX example](Bibliographies/ieeetran-bibtex/README.md): original example with a fictional reference.
- [PracTeX Journal](Academic%20Journals/practex-journal/README.md): six preserved source/reference files, license notices, and checksums.
- Kaobook, Legrand Orange Book, Tufte Book, and ebook-book: 50 incoming files matched existing Git blobs; no duplicate imports.

[Migration and validation](MIGRATION-2026-10-25.md) records the scope and remaining limitations.
